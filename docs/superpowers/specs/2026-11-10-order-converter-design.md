# 주문 엑셀 변환기 설계서

- 작성일: 2026-11-10
- 목적: 크몽 포트폴리오 1호. 쇼핑몰 셀러의 주문 엑셀을 CJ대한통운 송장 양식과 거래처별 발주서로 자동 변환한다.
- 성공 기준: 주문 파일과 매칭표를 넣으면 송장 파일 1개와 거래처별 발주서 zip 1개가 나오고, 크몽 상세페이지에서 "전/후"와 "샘플로 해보기"로 시연할 수 있다.

## 1. 구조

브라우저에서만 동작하는 정적 웹페이지. 서버 없음. 고객 파일은 컴퓨터 밖으로 나가지 않는다.

```
index.html   화면: 파일 올리기, 미리보기, 내려받기 (SheetJS·JSZip을 CDN에서 불러옴)
convert.js   변환 로직: 표 데이터(행 객체 배열)만 다룸. 파일 입출력 없음
sample.js    가상 주문 20건, 거래처 3곳 매칭표
convert.test.js  Node 내장 테스트(node:test)로 convert.js 검증
```

흐름:
1. 주문 엑셀 올리기 (스마트스토어 "발주/발송 관리" 다운로드)
2. 매칭표 엑셀 올리기 (상품명 → 거래처)
3. 미리보기: 주문 건수, 거래처 수, 매칭 안 된 상품 경고
4. 내려받기: `CJ대한통운_송장_YYYY-MM-DD.xlsx`, `발주서_YYYY-MM-DD.zip`

"샘플로 해보기" 버튼은 sample.js 데이터로 1~4를 바로 실행한다. 샘플 엑셀 2개를 내려받는 버튼도 둔다.

### 송장번호 되돌리기 (차별 기능)

발송 업무의 마지막 단계까지 처리한다: 주문 → 송장 접수 → **송장번호를 스마트스토어에 일괄 등록**.

5. 택배사에서 받은 송장번호 결과 엑셀 올리기
6. 내려받기: `스마트스토어_일괄발송_YYYY-MM-DD.xlsx` (스마트스토어 "엑셀 일괄발송"에 그대로 업로드)

송장 양식의 고객주문번호에 상품주문번호를 넣어 두었으므로, 원래 주문 파일 없이 결과 파일만으로 연결된다.
"샘플로 해보기"는 샘플 주문에 가짜 송장번호를 붙인 결과 파일로 5~6도 시연한다.

## 2. 데이터 형식

### 입력 ① 주문 엑셀 (스마트스토어)

첫 시트의 첫 행을 열 이름으로 본다. 열은 이름으로 찾으므로 순서는 상관없다.

필수 열: 상품주문번호, 상품명, 옵션정보, 수량, 수취인명, 수취인연락처1, 수취인연락처2, 우편번호, 배송지, 배송메세지

- 옵션정보, 수취인연락처2, 배송메세지는 값이 비어 있어도 된다(열은 있어야 함).
- 그 외 열은 무시한다.

### 입력 ② 매칭표

열: 상품명, 거래처. 상품명은 앞뒤 공백을 제거한 뒤 정확히 일치하는 것끼리 연결한다.

### 출력 ③ CJ대한통운 송장 양식 (xlsx 1개)

| 출력 열 | 값 |
|---|---|
| 받는분성명 | 수취인명 |
| 받는분전화번호 | 수취인연락처1 |
| 받는분기타연락처 | 수취인연락처2 |
| 받는분우편번호 | 우편번호 |
| 받는분주소 | 배송지 |
| 품목명 | 상품명 + 옵션정보(있으면 " / " 로 연결) |
| 내품수량 | 수량 |
| 배송메세지 | 배송메세지 |
| 고객주문번호 | 상품주문번호 |

공식 양식은 계약마다 다르므로, 출력 열 이름과 순서는 convert.js 맨 위 상수 한 곳에 모은다.
매칭 안 된 상품의 주문도 송장에는 포함한다.

### 출력 ④ 거래처별 발주서 (zip 안에 거래처마다 xlsx 1개)

파일명: `발주서_<거래처>_YYYY-MM-DD.xlsx`

열: 상품주문번호, 상품명, 옵션, 수량, 수취인명, 연락처, 우편번호, 주소, 배송메세지 (위탁배송 기준)

### 입력 ⑤ 택배사 송장번호 결과 엑셀

필수 열: 고객주문번호, 운송장번호. 그 외 열은 무시한다.
실제 열 이름은 택배사 화면에 따라 다를 수 있으므로 convert.js 맨 위 상수에 모은다.

### 출력 ⑥ 스마트스토어 일괄발송 양식 (xlsx 1개)

| 출력 열 | 값 |
|---|---|
| 상품주문번호 | 고객주문번호 |
| 배송방법 | `택배,등기,소포` (고정) |
| 택배사 | `CJ대한통운` (고정) |
| 송장번호 | 운송장번호 |

## 3. 오류 처리

| 상황 | 동작 |
|---|---|
| 파일을 열 수 없음(비밀번호, 엑셀 아님) | 비밀번호 해제 후 다시 내려받으라는 안내. 변환 안 함 |
| 필수 열 없음 | 빠진 열 이름을 모두 표시. 변환 안 함 |
| 매칭표에 없는 상품 | 송장엔 포함, 발주서에선 제외, 빨간 경고로 상품명과 주문번호 목록 표시 |
| 수량이 양의 정수가 아님 | 해당 상품주문번호 표시. 변환 안 함 |
| 전화번호·우편번호 앞자리 0 | 모든 값을 문자열로 다뤄 그대로 유지. 출력 셀도 문자열 |
| 거래처명에 파일명 금지 문자(`\ / : * ? " < > |`) | `_`로 바꿈 |
| 완전히 빈 행 | 건너뜀 |
| 송장번호 결과에 운송장번호가 빈 행 | 일괄발송 파일에서 제외, 주문번호 목록을 경고로 표시 |
| 송장번호 결과에 같은 주문번호가 두 번 | 첫 번째만 쓰고 경고 표시 |

## 4. 테스트

convert.js는 행 객체 배열만 받으므로 Node로 화면 없이 테스트한다. 의존성은 없다(node:test, node:assert).

테스트 항목:
1. 정상 변환: 송장 행 수, 품목명 결합, 거래처별 분리
2. 열 순서가 달라도 동작
3. 필수 열 누락 시 빠진 열 이름 반환
4. 매칭 안 된 상품: 송장 포함, 발주서 제외, 경고 목록
5. 전화번호 `010…`, 우편번호 `0…` 유지
6. 상품명 앞뒤 공백 무시
7. 수량 오류 시 주문번호와 함께 실패
8. 빈 행 건너뜀
9. 파일명 금지 문자 치환
10. 송장번호 되돌리기: 정상 변환(고정값 포함), 송장번호 앞자리 0 유지
11. 운송장번호 빈 행 제외 + 경고
12. 중복 주문번호는 첫 번째만 + 경고
13. 송장번호 결과에 필수 열 누락 시 빠진 열 이름 반환

마지막으로 브라우저에서 "샘플로 해보기"와 샘플 파일 업로드로 직접 확인한다.
